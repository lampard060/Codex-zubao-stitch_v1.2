# 技师端页面清单与功能说明

## 概述

本文档用于总结足宝项目中技师端当前包含的页面、每个页面的主要功能，以及页面之间的业务流转关系，方便产品评审、开发联调和项目交接。

## 页面总览

| 页面名称 | 访问路径 | 页面作用 |
| --- | --- | --- |
| 登录页（技师端登录入口） | `/app/login.html` | 技师通过手机号和密码登录系统，进入技师端业务流 |
| 技师工作台 | `/app/technician-home.html` | 技师日常工作的首页，展示当前状态、今日数据、进行中订单和后续安排 |
| 技师收益页 | `/app/technician-earnings.html` | 展示技师在今日、本月、年度维度的收益统计、趋势图和收益明细 |
| 技师个人资料页 | `/app/technician-profile.html` | 展示技师个人信息、门店签约关系、统计信息和个人功能菜单 |
| 申请加入门店页 | `/app/technician-join-shop.html` | 当技师尚未签约门店时，用于搜索门店、扫码加入或提交入驻申请 |

## 各页面功能说明

## 1. 登录页

- 文件路径：`/Users/frankzhang/Desktop/Claude-zubao-stitch_v1.2_副本/app/login.html`
- 页面定位：系统统一登录入口，包含商家端、技师端、消费者端三个角色切换，其中技师端是技师业务流的起点。

### 主要功能

- 支持在登录页切换到“技师端”登录表单。
- 支持输入手机号与密码进行登录。
- 登录成功后，根据角色跳转到对应首页。
- 技师端登录成功后，正常应进入技师工作台。

### 业务意义

- 是技师进入系统的唯一标准入口。
- 负责建立技师会话状态，为后续页面调用接口提供登录凭证。

## 2. 技师工作台

- 页面路径：`/app/technician-home.html`
- 当前情况：
  该页面是技师端的核心首页，当前浏览器预览和前端逻辑中已存在；在当前主工作区下 HTML 文件未落在 `app/` 目录，但同项目并行 worktree 中存在对应页面实现，且技师端脚本与导航均围绕该页面组织。
- 页面定位：技师进入系统后的主工作页面。

### 主要功能

- 展示当前工作状态：
  包括休息中、待钟中、服务中等状态。
- 支持上下班状态切换：
  可执行上班、下班打卡等动作。
- 展示今日关键数据：
  如今日完成单数、预估收入。
- 展示进行中订单：
  包括项目名称、房间、剩余时间、服务进度和操作按钮。
- 支持订单操作：
  当前已接入开始服务、完成服务的前端交互逻辑。
- 展示接下来的安排：
  当无排期时展示空状态提示。
- 底部导航：
  可跳转至工作台、收益、我的三个核心页面。

### 业务意义

- 是技师日常使用频率最高的页面。
- 承担技师“接单、服务、切换状态、查看今日经营情况”的核心职责。
- 若技师未签约门店，系统会从该页自动跳转到“申请加入门店页”。

## 3. 技师收益页

- 文件路径：`/Users/frankzhang/Desktop/Claude-zubao-stitch_v1.2_副本/app/technician-earnings.html`
- 页面定位：技师查看收入与收益走势的专用页面。

### 主要功能

- 支持时间维度切换：
  今日、本月、年度。
- 展示收益总览卡：
  包括总收入、完成订单数、服务总金额或提成收入。
- 展示收益趋势图：
  用柱状图表达不同时间段内的收益变化。
- 展示最近明细：
  列出最近完成的项目、时间、时长和收入金额。
- 支持查看全部明细入口：
  当前前端保留了“查看全部”交互入口。

### 业务意义

- 帮助技师快速理解自己的收入结构和趋势。
- 为技师判断工作表现、奖金变化和接单积极性提供数据依据。

## 4. 技师个人资料页

- 文件路径：`/Users/frankzhang/Desktop/Claude-zubao-stitch_v1.2_副本/app/technician-profile.html`
- 页面定位：技师查看和管理个人资料、签约状态的页面。

### 主要功能

- 展示个人头像、姓名、工号、个人简介。
- 提供资料相关操作：
  包括编辑资料、上传照片。
- 展示个人统计信息：
  如累计完成单数、客户评分。
- 展示当前签约门店：
  包括门店名称、地址、排班时间。
- 提供门店关系操作：
  包括申请解约、查看门店详情。
- 展示个人功能菜单：
  服务历史、设置、关于足宝。
- 支持退出登录。

### 业务意义

- 是技师管理个人身份信息和门店关系的中心页面。
- 同时承担签约状态查看与解约入口的职责。
- 与“申请加入门店页”构成签约前后两个主要状态页。

## 5. 申请加入门店页

- 文件路径：`/Users/frankzhang/Desktop/Claude-zubao-stitch_v1.2_副本/app/technician-join-shop.html`
- 页面定位：未签约技师的入驻申请页面。

### 主要功能

- 提供扫码加入门店入口。
- 支持输入门店名称或邀请码搜索门店。
- 展示推荐门店列表。
- 展示门店基础信息：
  如门店名称、地址、标签、在岗技师数量。
- 支持对门店发起“申请加入”动作。
- 当技师已签约门店时，系统会阻止继续留在该页并自动跳转回工作台。

### 业务意义

- 是未签约技师的主页面。
- 解决技师入驻、找店、申请审核的业务需求。
- 是技师从“未签约状态”进入“可接单状态”的关键起点。

## 页面之间的关系

### 正常业务流

1. 技师从登录页进入系统。
2. 若已有有效签约门店，进入技师工作台。
3. 若没有有效签约门店，进入申请加入门店页。
4. 在工作台中可进入收益页查看收入。
5. 在工作台或底部导航中可进入个人资料页管理个人信息与签约关系。
6. 在资料页申请解约后，技师会重新回到“申请加入门店页”的业务流。

### 底部导航关系

- 已签约技师：
  工作台、收益、我的。
- 未签约技师：
  申请、我的。
